# Reálne testovacie fotografie

V pôvodnom repozitári neboli žiadne fotografie meračov ani faktúr. Testy v OcrTest používajú výslovne syntetické bitmapy. Z ich výsledkov nemožno odvodiť úspešnosť na reálnych meračoch.

Keď budú dostupné fotografie s overeným správnym odpočtom, pridajte ich sem po odstránení osobných údajov a doplňte regresný test konkrétneho prípadu. Pri každej fotografii evidujte typ merača, jednotku, správne číslo a desatinnú čiarku. Pri faktúre aj presný význam ceny (DPH, jednotka, distribúcia), záloh a obdobia. Nejasný obrázok má očakávať ručnú kontrolu, nie uhádnuté číslo.
